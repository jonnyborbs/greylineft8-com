Release Notes

What's new in each version of Greyline FT8.

Version 1.1 Latest

The one that's the biggest update yet

I know I've shipped 14 updates to Greyline since I launched it back in June, but this is the single biggest set of additions yet. Buckle up, this is a big one!

Shoutouts
  • JK1TBLProposing a Cloudlog endpoint, providing an environment to test against, beta testing the app
  • KR4EODReporting a pretty major bug when working stations with a "/" in their callsign
  • ON4LDZSubmitting a Field Notes entry
  • VK2AWNWriting a great blog about Greyline!
Features
  • Greyline now supports Cloudlog and any Cloudlog-compatible logging endpoint! Just provide the API URL, API key, and Station Identifier and decide whether to auto-log your contacts to it.
  • The logging framework has been expanded to support QRZ, Cloudlog, and eventually WRL directly — stay tuned for that.
  • Gatherer mode now provides a manually editable queue. This is, as far as I can tell, a first for FT8/FT4 software. When you're working stations automatically, Greyline will queue them according to your preference (first heard, strongest signal, or furthest distance). But, with the new View Queue button, you can manually reprioritize them! Want to grab that station in Japan first? Been looking for that rare DX? Open up the queue and change the order that Gatherer will work them in.
  • Gatherer mode also now has a cooldown period — stations sending out of sequence or bad calls to you will be ignored for 5 minutes before we let them retry.
  • POTA auto spotting now sends a "Thanks and 73" message to the cluster when you end your activation or export your POTA log.
  • POTA auto-spotting can now be optionally disabled in Settings.
Fixes
  • We had a major issue with working stations that had a / in their callsign (think W1A1/3, for example) — the FT8 specification provides for how to handle this edge case, and it wasn't implemented correctly. Now, you can work these stations without a problem! If you ever saw callsigns that looked like "<…>" — you hit this bug. It's fixed now.
  • The Custom Message feature now follows the message queue timer and allows for full-length inputs.
  • Changed the label on the Stations Heard map from "All time" to "This Session", which is more accurate.
  • On iPhone or in some cases portrait mode iPad, text that doesn't fit in the allocated space in the Band Activity view will marquee gently, so you don't miss important info.
  • Added string validation to the manual QSO form — ensuring that callsigns, grid squares, and signal reports only contain valid characters that can be parsed by logging software.
  • Exporting a POTA log or cancelling an activation now inserts a visual line into your log, so you can see which entries were part of the activation more clearly.
  • We now require a grid square to be set (either manually or via Location Services) in order to transmit

Give it a try and please leave a review if you enjoy using Greyline! I hope it makes your activations just a tiny bit more joyful. Thanks for bringing me along and 73!

Version 1.0.13

The one where I improve signal decoding and add spotting!

Shoutouts
  • ON4LDZReporting issues with live band activity view
  • N9DNRReporting an issue with duplicate contacts being collected in Gatherer mode
  • KR4EODReporting discrepancies in signal report calculations
Features
  • Added live PSKReporter.info spotting. Spots are sent in 5 minute batches and include your callsign and grid location as well as the stations seen. Spotting is off by default, but can be activated in the Settings page.
  • Added color coded signal reports in the Band Activity view.
  • Added ability to filter the Logged Contacts view in the mapping page by time frame.
  • Added a toggle to allow collection of duplicate callsigns when operating in Hunter or Gatherer modes.
Fixes
  • SNR computation is now more accurate and accounts for real world noise as opposed to bench standard noise levels. Please note: comparing SNR computed in Greyline to that in iFTX or WSJT-X is not an apples-to-apples comparison. Differences in algorithms used as well as differences in AGC across device types plays a big role in these numbers.
  • When you navigate away from the Band Activity view, you are now automatically returned to the most recent signals upon your return.
  • Gatherer mode no longer collects duplicate callsigns by default. You can re-enable this behavior in the Settings view if you like.
  • Dropdown controls in the Mapping view sometimes re-drew slowly, but now they don't.

Give it a try and please leave a review if you enjoy using Greyline! I hope it makes your activations just a tiny bit more joyful. Thanks for bringing me along and 73!

Version 1.0.11

The one where I add a ton of POTA support!

Features
  • Greyline FT8 now helps you run a POTA activation end to end. Park lookup, spotting, logging, and export are all handled in-app.
  • Enable the POTA Activation mode in the CQ control panel and watch the magic. Greyline looks up parks near you (based on GPS or manual grid square,) adds the POTA addendum to your CQ calls, auto-spots you to the POTA cluster, marks your logged contacts as part of an activation, and enables a one-touch POTA.app compatible ADIF export.
  • POTA auto-spots happen when you start your activation, anytime you QSY to a new band, and periodically in between.

Give it a try — I'm really proud of this release. I hope it makes your activations just a tiny bit more joyful. Thanks for bringing me along and 73!

Version 1.0.9
Shoutouts
  • K4RZOMy favorite coyote — for identifying and helping me chase down some audio pipeline restore and timing bugs
Features
  • Big CTY data now automatically updates. We do a freshness check on each app launch, and force an update approximately once a week. Data loads are only about 300kb so bandwidth requirements are tiny.
  • Added a Time Debugging panel in the Settings menu. Most of you will never need this. But in case you see mis-timed messages, high instances of drift, or missed QSOs this screen will provide me the data I need to help track down the issue and make a better app for everyone.
Fixes
  • The audio pipeline now gracefully resumes when it's interrupted — whether you accidentally activated Siri, unplugged/switched audio devices, or started the latest episode of your favorite Star Trek Podcast by mistake. Greyline now detects and compensates for these interruptions.

Thanks and 73 to everyone for the feedback and bringing me along on your activations!

Version 1.0.7
Shoutouts
  • KJ5FVIRequesting selective log export
  • M0RVB, G7UFOSuggesting "Tune" functionality
Features
  • You can now select only specific QSOs to export to ADI from your log
  • Exporting to file will place a marker in your log showing when you last exported and how many log lines were saved

Version 1.0.6
Shoutouts
  • K0JGLReporting grid square lookup issues
  • IW2EYNSuggesting log import functionality
Features
  • Added the ability to import ADI formatted log files. Imported log entries will help you know who you've worked before. Note that imported log entries CAN be exported to a new ADI file, but can NOT be uploaded to QRZ — this is intentional, to prevent conflicts and duplication.
Fixes
  • Grid squares were occasionally returning partially correct lookup results, due to an "alphabetically first wins" algorithm where multiple states, provinces or countries were in a single grid. Now we show everyone — no favoritism here!
  • When you highlight a log row, we now use much more readable and high-contrast colors
